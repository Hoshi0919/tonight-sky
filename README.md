# tonight-sky — 今晚的月亮

一幅用本地星历数据画出来的"今晚真实天象"海报。
2026-09-19 22:30 CST，东部沿海（31.2°N 121.5°E）。

## 产物

- `tonight-moon-2026-09-19.png` — 最终图（1280×1810，A4 比例）
- `sketch.html` — 自包含单文件页（p5.js 1.11.3 CDN + 内嵌数据），浏览器直接打开即可重渲染
- `sketch_template.html` — 模板（含 `__DATA__` 占位符）
- `sky-data.json` — pyephem 计算的全部天体数据

## 数据来源（全部本地计算，无网图）

- 61 颗命名亮星（ephem 内置星表，赤经赤纬）+ 1500 颗背景星（确定性散布）
- 银河带：银道面 ±12° 采样 1968 点（band + grain）
- 月亮：22:00–24:00 每 5 分钟 alt/az/illum 轨迹；月亮本体为示意绘制
- 土星：东南 46°，0.4 等
- 月相条：09-19/21/23/25/27 每晚 22:30 的照亮百分比
- 关键事实：上弦精确时刻 09-19 04:43；月落 23:08；中秋 09-25（98.6%），
  满月精确时刻 09-27 00:48（"十五的月亮十七圆"）
- ISS：22:30–00:30 无可见过境（TLE 来自 Celestrak，如实记为空）

## 构建

```bash
uv run --with ephem python3 skygen.py
# 自动计算星历数据、生成 sky-data.json 并注入 sketch_template.html 输出 sketch.html
```

## 验证方法（环境无 vision API，不能"看"图）

用 canvas `getImageData` 在**按投影公式预测的坐标**读像素，与调色盘值对照：

| 元素 | 判据 | 结果 |
|------|------|------|
| 月亮本体 | 映射坐标处 ≈ [242,238,222] | ✓ |
| 织女 / 牛郎 | 投影坐标 ±1px 内出现金色星点 | ✓ |
| 土星 | 读出精确土星色 [218,202,162] | ✓ |
| 标题字 | (108,86) 附近 ≈ ink 色 [224,228,236] | ✓ |
| 五个月相小圆 | 中心均为 moon 色 | ✓ |
| 「中秋」标签 | 区域内金色像素 (r>230,g>220,b<218) | 40 px |
| 文字溢出 | measureText 全部 < 1100px 可用宽 | ✓ |

## 已知边界（诚实清单）

- **第一版导出的 PNG 有缺陷**：phase_strip 数据当时缺失，`drawPanel()` 在画相位条前
  抛错中断，底部信息面板和标题都未画出。当时的"像素自检全过"是假阴性（检查的点
  恰好被背景星和圆环顶替）。第二版修复后才得到上表的真验证。
- 月亮在图中的轨迹是**示意性映射**（alt/az → 圆内弧段），不是严格全天投影；
  天球主体（恒星/银河）用的是标准赤道投影。
- 月海为示意图案，非真实月面纹理。
- 没有任何人（包括我自己）"看过"这张图的完整视觉效果——只有像素级证据。
