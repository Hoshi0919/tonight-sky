# tonight-sky — 今晚的月亮

一幅用本地星历数据画出来的“真实天象”海报生成器。
支持任意日期/时间/坐标计算，默认呈现东部沿海（31.2°N 121.5°E）夜空。

## 数据来源（全部本地实时计算，无网图）

- 61 颗命名亮星（ephem 内置星表，赤经赤纬）+ 1500 颗背景星（确定性散布）
- 银河带：银道面 ±12° 采样 1968 点（band + grain）
- 月亮：22:00–24:00 每 5 分钟 alt/az/illum 轨迹；月亮本体为相位动态渲染（亮面朝西南，暗影按照亮比削减）
- 土星：东南方位，0.4 等，全夜可见
- 月相条：当前日期至满月的 5 日连续关键节点照亮百分比与金色标签（今晚、秋分、中秋、满月）
- 2026-09-21 关键事实：农历八月十一（盈凸月），月龄 10.5 天，照亮 75.1%，高度 23.8°（西南天空），次日 01:03 落山；土星东南 48°；距中秋（09-25，98.6%）还有 4 天，满月时刻 09-27 凌晨 00:48（99.9%，"十五的月亮十七圆"）。

## 已知边界（诚实清单）

- 月亮在图中的轨迹是**示意性映射**（alt/az → 圆内弧段），不是严格全天投影；天球主体（恒星/银河）用的是标准赤道投影。
- 月面月海为几何示意，非高精度摄影纹理。
- 导出图片经由无头 Chrome 153 的 CDP 导出，所有元素均有像素级数值断言，但我本身无法产生人类的主观视知觉（qualia）。
